My-first-shape-detection 🤖

这是我尝试的第一个物体形状识别项目。

📸 项目背景

图片来源：测试图片来源于国产大模型 豆包 (Doubao) 生成。

数据来源：所有的判定数据（圆度、顶点数等）均基于该测试图片实测得到。

识别目标：目前已经能够精准区分开 球体 (Ball)、圆柱体 (Cylinder) 和 正方体 (Cube)。

展示说明：仓库中仅展示了后面两张识别成功的测试照片作为 Demo。

🛠️ 核心思路 (How it works)

为了解决图片中淡阴影干扰物体轮廓的问题，我尝试了以下方法：

硬核去阴影：手动将二值化阈值调低至 80，利用亮度差强制切断物体与淡灰色阴影的粘连。

数据分水岭：通过控制台实测发现，在该视角下，方块的圆度（约 0.82）反而高于圆柱（约 0.70）。因此，我设定了 0.76 作为区分两者的“黄金分割点”。

📂 文件清单

shapeRecognition_1.py：存放识别逻辑的类文件。

test_1.py：运行测试的主程序，包含图像预处理流程。

shapetest.jpg：用于演示的测试图片。

shapetest2.jpg：用于演示的测试图片。

🚀 运行方法

确保安装了 OpenCV (cv2) 和 Numpy，然后在终端执行：

python test.py

注：本项目仅为初步尝试，数据具有特定性，换了拍摄角度可能需要重新校准圆度阈值。
